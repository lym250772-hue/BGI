# BGI 数据采集层技术文档

> **用途**: 答辩技术文档  
> **版本**: v4.2 (2026-06-04 品类扩展)  
> **覆盖**: 7品类 — 内容平台(5) + 二手/众包(闲鱼) + 社交IM(QQ群) + 主动人物钓鱼  
> **亮点**: 全平台评论采集 | v3持久化浏览器 | 品类扩展(闲鱼/QQ) | AI人物钓鱼 Skill | Telegram停用

## 三、微博 (AJAX API)

**端点**:
| 功能 | URL |
|------|-----|
| 搜索 | `weibo.com/ajax/statuses/search?q={kw}&page={p}&count={n}` |
| 评论 | `weibo.com/ajax/statuses/buildComments?id={id}&count={n}` |

## 四、知乎 (纯 HTTP API)

**端点**:
| 功能 | URL |
|------|-----|

## 五、小红书 (SSR提取 + 评论响应拦截)

**搜索流程**: 打开搜索页 → 提取 `window.__INITIAL_STATE__.search.feeds` → 解析 JSON

**评论流程 (v3)**: 打开笔记页 → 拦截 `/api/sns/web/v2/comment/page` → 解析评论JSON

**提取字段**: `note_id`, `image_list`, `tags`, `interact_info`(like/collect/comment), `xsec_token`

**反爬**: v3持久化浏览器 (`launch_persistent_context`), 高斯延迟(6-16s), 贝塞尔鼠标, 随机滚动/回滚

## 六、抖音 (X-Bogus签名 + 评论响应拦截)

**搜索流程**: `page.evaluate(fetch)` + X-Bogus签名 → SSR `body.innerText` 正则提取

**评论流程 (v3)**: 打开视频页 → 拦截 `/aweme/v1/web/comment/list/` → 解析评论JSON

**提取字段**: 描述/作者/点赞/时长/日期、`video_cover_url`、图集 `image_list`、`aweme_id`

**反爬**: v3持久化浏览器 + 高斯延迟(5-15s) + 拟人滚动

## 七、闲鱼 (v3持久化浏览器 + SSR+DOM双解析) 🆕

**搜索流程**: 打开搜索页 → 提取 `__INITIAL_STATE__` → DOM解析兜底 → API拦截补充

**数据获取**: 三层策略
1. SSR 提取 (`__INITIAL_STATE__` / `__NEXT_DATA__` / `__NUXT__`)
2. DOM 解析 (多种选择器自适应)
3. API 响应拦截 (`/search`, `/mtop.taobao.idle.search`)

**提取字段**: title + description, price, seller_rating(芝麻信用), location(IP属地), listing_status, image_list

**反爬**: 阿里系安全极严 — 强制非headless + Edge内核 + 高斯延迟(5-16s) + 贝塞尔鼠标 + 人类滚动(12-15%回滚) + 首页浏览(8-10%) + 每日限量20-30条

**文件**: `collectors/spiders/xianyu_spider.py`
- `XianyuSearchSpider` — 继承 BaseSpider，v3持久化浏览器
- `XianyuCollector` — BaseCollector 实现
- CLI: `python main.py login-xianyu` / `python main.py collect -p xianyu -k "账号交易"`

## 八、QQ群聊 (NapCatQQ WebSocket + 被动监听) 🆕

**架构**: QQ桌面端(NTQQ) ←IPC→ NapCatQQ ←WebSocket→ napcat_bridge.py → QQGroupCollector

**技术选型**: NapCatQQ — 基于官方NTQQ进程的无头客户端，非协议逆向。WebSocket实时推送群消息。

**消息格式**: OneBot 11标准
```json
{"post_type": "message", "message_type": "group",
 "group_id": 123456, "user_id": 789012,
 "sender": {"nickname": "用户昵称"},
 "raw_message": "消息内容", "message_id": 123}
```

**数据模型**: `IMMessageItem` (group_id/sender_uid/sender_nickname/content_raw/message_id/reply_to_id) → `im_to_intel()` → 统一 IntelItem

**采集方式**: 
- 被动监听已加入的群消息
- 批处理: 50条或5分钟 flush
- 群发现: 用户手动在QQ客户端搜索灰产关键词加入群

**文件**: `bridges/napcat_bridge.py` / `collectors/qq_group_collector.py`

## 九、AI人物钓鱼 (Persona Engine) 🆕

**核心能力**: LLM驱动的虚拟人物，以"想参与灰产"的姿态与卖家对话，钓取灰产情报。

**架构**:
```
PersonaEngine → LLM Driver (DeepSeek) → 人物回复生成
     │              │
     └── SafetyGuard (安全护栏，每消息过滤)
                    │
            ┌───────┴───────┐
            │ 进入检查       │ 外出检查
            │ (触发词+正则)  │ (禁止模式)
            └───────────────┘
```

**3个人物Profile (YAML)**:
| 人物 | 身份 | 目标 |
|------|------|------|
| `ecommerce_buyer` | 电商卖家小张 | 钓取涨粉/刷量服务情报 |
| `brusher_seeker` | 大学生小李 | 了解刷单/水军招募链 |
| `account_unban` | 自媒体王姐 | 收集解封/账号交易情报 |

**安全护栏 (SafetyGuard)**:
- 退出触发词: 先付款/定金/保证金/发身份证/下载APP/加微信私聊...
- 禁止模式: 正则匹配付款请求/身份验证/加密渠道引导/线下交易
- 外出过滤: 禁止人物回复中包含同意付款/提供个人信息/参与违法活动
- 兜底机制: 安全触发→自动替换为安全消息

**Phase**: 
- Phase 1: LLM-LLM模拟（对话双方均为AI，安全测试）
- Phase 2: 连接真实平台（闲鱼私聊/QQ群@回复）

**文件**: `persona/engine.py` / `persona/safety.py` / `persona/llm_driver.py` / `persona/personas/*.yaml`

## 十、v3 持久化浏览器引擎

**核心方案**: `playwright.chromium.launch_persistent_context(user_data_dir, channel="msedge")`

**优势**:
- 一次登录永久复用（session/cookie/LocalStorage全保留）
- Edge内核指纹更可信
- 无批次强制休息，自然节奏（高斯分布5-16s间隔）
- 偶尔回首页浏览（8-10%概率）模拟真实用 户

**脚本**:
| 平台 | 脚本 | 用法 |
|------|------|------|
| 小红书 | `xiaohongshu_comments_v3.py` | `--max 200` |
| 抖音 | `douyin_comments_v3.py` | `--max 200` |

## 八、贴吧 (JSON API + 回复提取) 🆕

**突破**: 2026-06-03 通过 Playwright 网络拦截抓包，发现内部搜索 API，实现从 Playwright DOM 0.03条/秒 → HTTP JSON ~10条/秒。

**搜索端点**:
```
tieba.baidu.com/mo/q/search/multsearch
  ?rn=20&word={关键词}&pn={页码}
  &subapp_type=pc&_client_type=20
```

**特点**:
- 纯 HTTP GET，**无需 sign 参数**（实测 sign/空/随机 均返回相同结果）
- Cookie 认证（BDUSS + BAIDUID）
- 返回完整 JSON：主帖内容 + 作者 + 图片列表 + 回复数

**数据质量**（30条样本）:
| 指标 | 比例 |
|------|:--:|
| 长内容 (>50字) | 73% |
| 含图片 | 77% |
| 有作者 | 100% |

**回复提取**: Playwright打开帖子页 → DOM提取 `.pb-comment-item`（新版React页面），已采集192篇/876条

**文件**: `collectors/spiders/tieba_api_spider.py`
- `TiebaAPISpider` — 独立使用，`search(keyword, max_pages, rn)`
- `TiebaSpider(TiebaAPISpider)` — 兼容旧 `search_and_parse()` 接口，可直接替换旧 Playwright 版本
- `collectors/comment_collector.py` → `fetch_tieba_replies()` — 回复采集

## 十二、统一数据格式 (IntelItem)

```python
@dataclass
class IntelItem:
    platform: str           # weibo/zhihu/douyin/xianyu/qq_group/...
    content_raw: str        # 原始内容
    content_type: str       # text/video/image/conversation
    source_url: str         # 原始链接
    author_uid: str         # 作者ID
    author_username: str    # 作者昵称
    group_id: str           # 分组(关键词/吧名/群号/persona名)
    collected_at: datetime
    message_id: int | None
    # 🆕 v4.2 市场平台扩展
    price: float            # 商品价格 (闲鱼等)
    seller_rating: str      # 卖家信用评级
    location: str           # 卖家所在地
    listing_status: str     # 商品状态 (active/sold/deleted)
    # 媒体
    image_urls: list[str]   # 图片列表
    video_cover_url: str    # 视频封面
    metadata: dict          # 平台特定字段
```

**即时消息模型 (IMMessageItem)** — QQ群聊等社交IM专用:
```python
@dataclass
class IMMessageItem:
    platform: str           # qq_group
    group_id: str           # 群号
    group_name: str         # 群名
    sender_uid: str         # 发送者ID
    sender_nickname: str    # 发送者昵称
    content_raw: str        # 消息内容
    message_id: str         # 消息ID
    reply_to_id: str        # 回复消息ID
```

## 十四、反爬策略

| 策略 | 实现 |
|------|------|
| 持久化浏览器 | `launch_persistent_context` + Edge内核，一次登录永久复用 |
| UA 轮换 | Mac/Windows Chrome UA 随机 |
| webdriver 隐藏 | `navigator.webdriver = false` |
| 自然节奏 | 高斯分布延迟 5-16s（无固定批次强制休息） |
| 拟人操作 | 贝塞尔鼠标(15-30步)、随机滚动(含回滚)、偶尔回首页(8-10%) |
| Cookie 注入 | EditThisCookie 格式 → Playwright |
| 首页预热 | start() 先访问首页 |
| 增量采集 | 按关键词记录最后时间戳 |
| 增量保存 | 每10条保存一次，中断可续 |
