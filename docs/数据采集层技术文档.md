## 二、渠道技术方案

### 2.1 微博 — AJAX API 直调（最快渠道）

**技术路线**: 纯 HTTP 请求，零浏览器开销

**核心发现**: 微博内部 AJAX 接口 `weibo.com/ajax/statuses/search` 仅需 Cookie 认证，无需浏览器签名，返回结构化 JSON。

**实现** (`collectors/spiders/weibo_api_spider.py`):

```python
class WeiboAPISpider:
    SEARCH_API = "https://weibo.com/ajax/statuses/search"
    HOT_SEARCH_API = "https://weibo.com/ajax/side/hotSearch"

    def search(self, keyword, max_pages=3, count=20):
        # Cookie 注入到 requests.Session
        self._session.cookies.set(...)
        # 逐页请求
        for page in range(1, max_pages + 1):
            url = f"{SEARCH_API}?q={keyword}&page={page}&count={count}"
            resp = self._session.get(url, headers=self.headers)
            data = resp.json()
            for status in data.get("statuses", []):
                yield self._parse_status(status, keyword)
```

**请求头配置**:
```
User-Agent: Chrome/131.0.0.0 (Windows)
Referer: https://weibo.com/
X-Requested-With: XMLHttpRequest
Cookie: SUB=...; SUBP=...; (从 data/raw/weibo_cookies.json 加载)
```

**API 响应结构**:
```json
{
  "ok": 1,
  "statuses": [
    {
      "id": 5305424066120242,
      "text_raw": "刷单被骗...",
      "user": {"id": "123", "screen_name": "用户昵称"},
      "created_at": "Tue Jun 02 18:12:10 +0800 2026",
      "reposts_count": 0, "comments_count": 0, "attitudes_count": 0
    }
  ],
  "total": 958739
}
```

**性能**: 12.8条/秒，5关键词×2页 = 185条/14.4秒，零错误

**反爬对抗**: 无。该接口是微博前端 AJAX 接口，仅校验 Cookie，不检测自动化。间隔 0.8-2.0s 随机延迟即可。

**灵感来源**: 论文 `G:\HEU\毕业论文\初稿2\cs.py` 和 `一级评论获取.py` 中使用的 `weibo.com/ajax/` 方案。

### 2.2 抖音 — Playwright 首页搜索框 + 正则文本提取

**技术路线**: 浏览器自动化（绕过验证码）+ 纯文本正则解析（绕过 API 签名）

**问题分析**:

抖音反爬是三层防护体系：

```
┌──────────────────────────────────────────────────┐
│  Layer 1: 服务端验证码                             │
│  直接访问 /search/ → HTTP 返回 "验证码中间页"       │
│  检测点: 请求来源（Referer）、浏览器指纹            │
├──────────────────────────────────────────────────┤
│  Layer 2: 客户端签名校验                           │
│  搜索 API (aweme/v1/web/search/item/) 返回:          │
│  {"search_nil_info": {"search_nil_type":          │
│   "params_check", "search_nil_item":              │
│   "invalid_app"}}                                  │
│  需要: msToken, X-Bogus, _signature (JS动态生成)   │
├──────────────────────────────────────────────────┤
│  Layer 3: 信任登录弹窗                             │
│  首页出现 trust-login-dialog-mask 遮罩             │
│  检测到 webdriver 标记时触发                        │
└──────────────────────────────────────────────────┘
```

**解决方案 — 绕过 Layer 1（验证码）**:

关键发现：从首页搜索框自然过渡到搜索页（`jingxuan/search/`）不会触发验证码，但直接 URL 导航到 `/search/` 会。

```
正确路径: 首页 → 点击搜索框 → 键入关键词 → Enter → jingxuan/search/
错误路径: 直接访问 /search/关键词 → 验证码中间页
```

实现（`collectors/spiders/douyin_spider.py:_search_via_homepage`）:
```python
# Step 1: 首页建立会话
self._page.goto("https://www.douyin.com/", ...)
# Step 2: JS移除遮罩
self._page.evaluate("mask.remove()")
# Step 3: Playwright原生键盘操作（必须用原生，JS dispatchEvent不触发React导航）
self._page.mouse.click(500, 300)  # 确保焦点
self._page.locator('input').first.click()  # 点击搜索框
self._page.keyboard.type(keyword, delay=100)  # 模拟打字
self._page.keyboard.press('Enter')  # 触发搜索
# Step 4: 等待搜索结果渲染
time.sleep(6)
```

**解决方案 — 绕过 Layer 2（API 签名）**:

API 需要客户端签名，但搜索结果的文本内容已完整渲染在 DOM 的 `body.innerText` 中。

搜索结果在 body 中的固定文本模式：
```
01:48          ← 视频时长 (MM:SS)
4965           ← 点赞数
s单罚款规则出来多久了...  ← 视频描述
@后生电商       ← 作者昵称
· 2025年3月26日 ← 发布日期
```

正则提取（`_parse_from_body_text`）:
```python
pattern = re.compile(
    r'(\d{2}:\d{2})\s*\n\s*([\d.]+[亿万]?)\s*\n\s*(.+?)\s*\n\s*'
    r'@(.+?)\s*\n\s*·\s*(.+?)(?=\n\d{2}:\d{2}|\n相关搜索|\n\s*$)',
    re.DOTALL
)
```

**解决方案 — 绕过 Layer 3（信任弹窗）**:

```python
# 反检测措施
browser.launch(args=['--incognito', '--disable-blink-features=AutomationControlled'])
page.add_init_script(
    "Object.defineProperty(navigator, 'webdriver', {get: () => false});"
)
# 轮换 User-Agent
ua = random.choice([Mac_Chrome_UA, Windows_Edge_UA])
# JS 移除遮罩
page.evaluate("document.querySelectorAll('[class*=\"mask\"]').forEach(m => m.remove());")
```

**性能**: 22条搜索结果/次搜索，0.4条/秒（受 Playwright 浏览器开销限制）

**限制**: 无法获取视频 `aweme_id` 和评论区内容（这些需要 API 签名）

### 2.3 知乎 — Playwright API 直调

**技术路线**: Playwright 浏览器内 `page.evaluate(fetch)` 调知乎搜索 API

知乎搜索 API 在浏览器内自动携带认证 Cookie 和 CSRF Token，无需额外签名。

**实现** (`collectors/spiders/zhihu_spider.py`):
```python
def _call_search_api(self, keyword, offset=0):
    js_code = f"""
    async () => {{
        const resp = await fetch(
            '/api/v4/search_v3?q={keyword}&offset={offset}&limit=20',
            {{ credentials: 'include' }}
        );
        return await resp.json();
    }}
    """
    return self._page.evaluate(js_code)
```

**反爬**: 知乎反爬较弱，仅需 Cookie（`z_c0`）和基础 UA。间隔 1.5-4.0s 随机延迟。

**性能**: 0.2条/秒，稳定零错误

### 2.4 小红书 — Playwright API 拦截 + DOM 兜底

**技术路线**: 拦截 XHR 搜索响应获取 JSON → DOM 解析兜底

小红书搜索页加载时，前端发起 XHR 请求获取搜索结果。通过 Playwright 的 `page.on("response")` 拦截这些 API 响应。

**实现** (`collectors/spiders/xiaohongshu_spider.py`):
```python
def _setup_interception(self):
    self._page.on("response", lambda resp: {
        if "/api/sns/web/v1/search/notes" in resp.url:
            self._api_responses.append(resp.json())
    })
```

**DOM兜底**: 当 API 拦截失败时，从页面 DOM 解析笔记卡片。

**性能**: 0.3条/秒

### 2.5 贴吧 — Playwright DOM 解析

**技术路线**: Playwright 加载搜索页 → DOM 提取搜索结果

**新版页面兼容修复** (2026-06-02):

贴吧新版搜索结果页 `<a>` 标签的 `innerText` 为空（使用 `class="action-link-bg"` 作为纯装饰链接），文本内容实际在父级 `.thread-content-box` 容器中。

**修复前**（旧代码，0结果）:
```javascript
document.querySelectorAll('a[href*="/p/"]').forEach(a => {
    const text = a.innerText.trim();  // 新版返回空字符串
    if (!text || text.length < 8) return;  // 全部被过滤
});
```

**修复后**（`tieba_spider.py:_parse_from_dom`）:
```javascript
document.querySelectorAll('div.thread-content-box').forEach(box => {
    const link = box.querySelector('a[href*="/p/"]');
    const fullText = box.innerText.trim();  // 从父容器取文本
    const lines = fullText.split('\n');
    const forum = lines[0];       // 吧名
    const title = lines.slice(2); // 跳过作者行
    results.push({title, forum, threadId: tid});
});
```

**搜索结果页结构**:
```
div.thread-content-box
  ├── 国产动画吧           ← 吧名
  ├── 布什鸽们你 发布于...  ← 作者+日期
  ├── 真让师兄碰上哪吒fq了...← 帖子正文
  ├── a.action-link-bg     ← 空链接(装饰)
  └── a.comment-link-zone  ← 回复数
```

**性能**: 0.03条/秒（最慢渠道，因为需要加载完整页面+React渲染）

## 三、反爬对抗体系

### 3.1 六件套基础反爬（所有 Playwright 渠道共用）

| 措施 | 实现 | 对抗目标 |
|------|------|------|
| UA池 | 7个随机UA轮换 | 浏览器指纹一致性检测 |
| webdriver隐藏 | `navigator.webdriver = false` | 自动化检测 |
| Cookie注入 | 从文件/环境变量加载，标准化格式注入 | 身份认证 |
| 随机间隔 | 1.5-6.0s自适应延迟 | 频率限制 |
| 首页预热 | 先访问首页建立会话再搜索 | 行为模式检测 |
| 验证码检测 | `_is_blocked()` 检查页面标题 | 快速发现拦截 |

### 3.2 抖音专项反爬

| 措施 | 说明 |
|------|------|
| Incognito模式 | `--incognito` 参数，隔离浏览器状态 |
| 双UA轮换 | Mac Chrome / Windows Edge 交替使用 |
| 原生键盘操作 | `page.keyboard.type()` 而非 JS `dispatchEvent` |
| 遮罩清除 | JS 移除 `trust-login-dialog-mask` |
| 首页渐进 | 首页→搜索框→搜索页，不直接跳搜索URL |

## 四、数据流

### 4.1 完整采集→入库流程

```
main.py collect -p <平台> -k <关键词>
    │
    ▼
registry.get_collector(platform)     # 工厂模式获取采集器
    │
    ▼
collector.collect() → Iterator[IntelItem]
    │
    ▼
main.py collect 命令                 # 批量累积 IntelItem
    │
    ▼
mysql.insert_raw_intel()             # 批量 INSERT (100条/批)
    │  └─ ods_raw_intel 表
    │     raw_status = "RAW_COLLECTED"
    │
    ▼
main.py clean -l 500                 # 清洗管道
    │  └─ SimHash 去重 → 平台感知噪声过滤 → 优先级标记 → 实体检测
    │     raw_status → "CLEANED" / "DISCARDED"
    │     └─ dwd_clean_intel 表
    │
    ▼
main.py analyze -l 200               # 分析管道 (需 LLM Key)
    │  └─ L1→L3分类 → 实体提取 → 风险评分 → 图谱关联
    │     raw_status → "ANALYZED"
    │     └─ dwd_intel_analysis + dwd_entity + Neo4j + Milvus
    │
    ▼
main.py ui                           # Streamlit 仪表盘
```

## 七、技术创新点总结

1. **微博 AJAX API 方案**: 发现并利用 `weibo.com/ajax/statuses/search` 接口，将微博采集从浏览器方案（0条/61秒）提升到纯 HTTP 方案（185条/14.4秒），速度提升 80 倍

2. **抖音三层反爬绕过**: 
   - Layer 1（验证码）: 首页搜索框渐进式导航替代直接 URL 跳转
   - Layer 2（API签名）: body.innerText 正则文本提取替代 API 解析
   - Layer 3（遮罩弹窗）: JS 移除 + Incognito + webdriver 隐藏

3. **贴吧新版 DOM 适配**: 发现并修复贴吧搜索结果页 `<a>` 标签 innerText 为空的渲染变更，改为从父容器 `.thread-content-box` 提取

4. **统一 IntelItem 数据格式**: 5 个异构平台统一输出为同一种数据结构，清洗和分析层无需关心来源

5. **工厂模式采集器注册**: `registry.py` 实现平台→采集器的解耦映射，新增渠道只需注册工厂函数即可接入
