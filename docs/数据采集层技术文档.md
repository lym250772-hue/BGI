## 三、微博 (AJAX API)

**端点**:
| 功能 | URL |
|------|-----|
| 搜索 | `weibo.com/ajax/statuses/search?q={kw}&page={p}&count={n}` |
| 评论 | `weibo.com/ajax/statuses/buildComments?id={id}&count={n}` |
| 热搜 | `weibo.com/ajax/side/hotSearch` |

**Cookie**: `data/raw/weibo_cookies.json` (/ `BGI_WEIBO_COOKIES` 环境变量)

## 四、知乎 (纯 HTTP API)

**端点**:
| 功能 | URL |
|------|-----|
| 搜索 | `/api/v4/search_v3?q={kw}&type=content&offset={o}&limit=20` |
| 答案 | `/api/v4/questions/{qid}/answers?limit=3` |
| 评论 | `/api/v4/answers/{aid}/comments?limit=10` |

**Cookie**: `data/raw/zhihu_cookies.json`（需要 z_c0 + d_c0）

## 五、小红书 (API拦截)

**流程**: 打开搜索页 → 拦截 `/api/sns/web/v1/search/notes` → 解析 JSON → DOM 兜底

**提取字段**: `note_id`, `image_list`, `tags`, `interact_info`(like/collect/comment)

**限制**: 评论 API 需要 X-s 签名，未实现

## 六、抖音 (首页搜索框)

**流程**: `douyin.com` 首页 → 搜索框输入关键词 → Enter → `body.innerText` 正则提取

**提取字段**: 描述/作者/点赞/时长/日期、`video_cover_url`、图集 `image_list`

**限制**: 无法获取 aweme_id（需 msToken 签名），无法采集评论

## 七、贴吧 (JSON API) 🆕

**突破**: 2026-06-03 通过 Playwright 网络拦截抓包，发现内部搜索 API，实现从 Playwright DOM 0.03条/秒 → HTTP JSON ~10条/秒。

**搜索端点**:
```
tieba.baidu.com/mo/q/search/multsearch
  ?rn=20&word={关键词}&pn={页码}
  &subapp_type=pc&_client_type=20
```

**特点**:
- 纯 HTTP GET，**无需 sign 参数**（实测 sign/空/随机 均返回相同结果）
- Cookie 认证（BDUSS + BAIDUID）
- 返回完整 JSON：主帖内容 + 作者 + 图片列表 + 回复数

**数据质量**（30条样本）:
| 指标 | 比例 |
|------|:--:|
| 长内容 (>50字) | 73% |
| 含图片 | 77% |
| 有作者 | 100% |

**限制**: 回复 API (`c.tieba.baidu.com/c/f/pb`) 需额外签名暂不可用，但搜索 API 已含主帖完整内容。

**文件**: `collectors/spiders/tieba_api_spider.py`
- `TiebaAPISpider` — 独立使用，`search(keyword, max_pages, rn)`
- `TiebaSpider(TiebaAPISpider)` — 兼容旧 `search_and_parse()` 接口，可直接替换旧 Playwright 版本

## 八、统一数据格式 (IntelItem)

```python
@dataclass
class IntelItem:
    platform: str           # weibo/zhihu/douyin/...
    content_raw: str        # 原始内容
    content_type: str       # text/video/image
    source_url: str         # 原始链接
    author_uid: str         # 作者ID
    author_username: str    # 作者昵称
    group_id: str           # 分组(关键词/吧名)
    collected_at: datetime
    message_id: int | None
    image_urls: list[str]   # 图片列表
    video_cover_url: str    # 视频封面
    metadata: dict          # 平台特定字段
```

## 十、反爬策略

| 策略 | 实现 |
|------|------|
| UA 轮换 | Mac/Windows Chrome UA 随机 |
| webdriver 隐藏 | `navigator.webdriver = false` |
| Cookie 注入 | EditThisCookie 格式 → Playwright |
| 随机间隔 | 1.5-4.0s |
| 首页预热 | start() 先访问首页 |
| 增量采集 | 按关键词记录最后时间戳 |
