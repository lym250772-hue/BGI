## 采集命令

### 全通道并发采集（推荐，v2.0 新增）

```bash
# 所有平台同时跑，统一关键词
python main.py collect-all -k "刷单,接码,跑分" --max-pages 3

# 指定平台 + 关键词文件
python main.py collect-all --keyword-file data/grey_keywords.json --max-pages 2

# 只跑微博+知乎（纯 HTTP，最快）
python main.py collect-all -k "刷单" --platforms weibo,zhihu --max-pages 2

# 控制速率
python main.py collect-all -k "刷单" --rpm-per-platform 15 --batch-size 200

# Ctrl+C 中断自动保存断点，下次运行自动恢复
```

### 单平台采集

```bash
# 微博（纯 HTTP，12.8条/秒）★最快
python main.py collect -p weibo -k "关键词1,关键词2" --max-pages 3

# 知乎（纯 HTTP，v2.0 升级）3-5条/秒
python main.py collect -p zhihu -k "刷单,接码" --max-pages 2

# 小红书（Playwright API拦截）
python main.py collect -p xiaohongshu -k "关键词1,关键词2" --max-pages 3

# 抖音（首页搜索框方案）
python main.py collect -p douyin -k "无人直播" --max-pages 2

# 贴吧（Playwright DOM解析，较慢0.03条/秒）
python main.py collect -p tieba -k "刷单,接码" --max-pages 3

# Telegram（需先配置 API ID/Hash）
python main.py collect -p telegram --tg-groups "group1,group2"
```

### 采集选项

| 选项 | 默认值 | 说明 |
|------|:--:|------|
| `--max-pages` | 10 | 每关键词最大翻页数 |
| `--max-items` | 0 | 每关键词最大条目数（0=无限制） |
| `--fetch-replies/--no-fetch-replies` | True | 是否同时采集评论/回复 |
| `--incremental/--no-incremental` | False | 增量采集（跳过已采集的） |
| `--batch-size` | 100 | MySQL 批量插入大小 |
| `--rpm-per-platform` | 20 | 每平台每分钟最大请求数 |

## 完整工作流

```bash
# 1. 全量采集（5平台并发，含评论）
python main.py collect-all -k "刷单,接码,跑分,账号出售" --max-pages 3

# 2. 清洗去重
python main.py clean -l 500

# 3. OCR 图文提取（小红书/抖音的图片文字识别）
python main.py ocr -p douyin,xiaohongshu -l 100

# 4. 分类+实体抽取+风险评分
python main.py analyze -l 200

# 5. 查看结果
python main.py ui

# 或者一步到位（不含采集，需数据库有数据）
python main.py run -l 500    # clean → analyze
```

## 平台登录

```bash
python main.py login -p weibo        # 微博
python main.py login -p zhihu        # 知乎
python main.py login -p tieba        # 贴吧
python main.py login -p xiaohongshu  # 小红书
python main.py login -p douyin       # 抖音
python main.py login -p all          # 全部依次登录
```

- 浏览器自动打开 → 手动扫码/输入密码 → 终端按 Enter → Cookie 自动保存
- Cookie 保存在 `data/raw/{platform}_cookies.json`
- 有效期通常 7-30 天，过期后重新运行登录命令即可

## 故障排查

| 症状 | 原因 | 解决 |
|------|------|------|
| 采集返回 0 条 | Cookie 过期 | `python main.py login -p <平台>` |
| 抖音 0 条 | 反爬/搜索引擎变动 | 换关键词重试或等30分钟 |
| 小红书 0 条 | API拦截失败/签名变更 | 等30分钟后重试 |
| 贴吧 0 条 | 百度验证码 | Cookie过期，重新登录 |
| Docker 连不上 | Docker Desktop 未启动 | 启动 Docker Desktop |
| GBK 乱码 | Windows 默认编码 | `PYTHONIOENCODING=utf-8` |
| LLM 401 错误 | API Key 无效 | 编辑 `.env` 填入真实 Key |
| SimHash 警告 | C 扩展未安装 | 正常——使用纯 Python 回退 |
