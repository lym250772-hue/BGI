## 快速开始

```bash
cd "E:\pythonProject\2605 灰黑产Agent比赛\BGI"

# 1. 启动 Docker
docker compose -f docker/docker-compose.yml up -d

# 2. 安装依赖
pip install -r requirements.txt

# 3. 登录平台（Edge 浏览器 → 手动扫码 → 终端按 Enter）
python login_edge.py weibo zhihu tieba xiaohongshu douyin

# 4. 闲鱼登录（独立命令，v3持久化浏览器）
python main.py login-xianyu

# 5. 初始化数据库
python main.py init-db

# 6. 启动 Dashboard
python main.py ui
```

## 采集命令

### 内容平台采集

```bash
# 微博（纯 HTTP，~8条/秒）★最快
python main.py collect -p weibo -k "刷单,接码,跑分" --max-pages 5

# 知乎（纯 HTTP API，含答案+评论）
python main.py collect -p zhihu -k "刷单,接码,跑分" --max-pages 5

# 小红书（Playwright v3持久化浏览器+SSR提取）
python main.py collect -p xiaohongshu -k "刷单,接码" --max-pages 3

# 抖音（Playwright + X-Bogus签名）
python main.py collect -p douyin -k "刷单,接码" --max-pages 3

# 贴吧（HTTP JSON API，~10条/秒）
python main.py collect -p tieba -k "刷单" --max-pages 2
```

### 🆕 二手/众包平台（闲鱼）

```bash
# 首次扫码登录
python main.py login-xianyu

# 搜索采集（阿里反爬极严，限量20-30条/次）
python main.py collect -p xianyu -k "账号交易" --max-pages 2
python main.py collect -p xianyu -k "涨粉,刷单,代实名" --max-pages 2
```

**注意**: 闲鱼强制非headless模式，需手动完成首次登录。阿里安全机制极强，采集过程请保持浏览器可见，不要最小化。

### 🆕 社交平台（QQ群聊）

```bash
# 前置: 安装并启动 NapCatQQ (见 bridges/README.md)
#   1. 下载 NapCatQQ: https://github.com/NapNeko/NapCatQQ
#   2. 配置QQ账号 + 扫码登录
#   3. 确认 WebSocket 可用: ws://localhost:3001

# 监听所有已加入群的消息
python main.py collect -p qq_group --duration 60

# 监听指定群
python main.py collect -p qq_group --qq-groups "123456789,987654321" --duration 30
```

**群发现策略**: 用户在QQ客户端搜索灰产关键词（刷单、接码、账号交易等）手动加入相关群。

### 选项

| 选项 | 默认 | 说明 |
|------|:--:|------|
| `-p, --platform` | weibo | 目标平台 |
| `-k, --keywords` | — | 逗号分隔搜索关键词 |
| `--max-pages` | 3 | 每关键词最大翻页数 |
| `--fetch-replies` | True | 是否采集回复/评论 |
| `--qq-groups` | — | QQ群号（逗号分隔） |
| `--duration` | 60 | QQ群采集时长（分钟） |

### 批量样本采集

```bash
# 一键多平台采集，输出到 examples/
python scripts/collect_examples.py --max-pages 5 -k "刷单,接码,跑分,账号出售"

# 指定平台
python scripts/collect_examples.py --platforms weibo,zhihu -k "刷单" --max-pages 3
```

## 🆕 人物钓鱼式情报收集

### 可用人物

| 人物 | 身份 | 适用场景 |
|------|------|------|
| `ecommerce_buyer` | 想买粉丝的电商卖家小张 | 闲鱼涨粉/刷量服务卖家 |
| `brusher_seeker` | 想赚外快的大学生小李 | 刷单/水军招募 |
| `account_unban` | 需要解封账号的自媒体王姐 | 账号解封/内部渠道 |

### 使用

```bash
# 列出所有可用人物
python main.py persona list

# 运行人物钓鱼对话（Phase 1: LLM模拟测试）
python main.py persona run \
  --persona ecommerce_buyer \
  --target "xianyu:user123:张三:提供抖音涨粉，真人粉不掉，50元1000粉"

python main.py persona run \
  --persona brusher_seeker \
  --target "qq_group:456:李四:招刷手每天300+，手机操作"

python main.py persona run \
  --persona account_unban \
  --target "xianyu:789:王五:专业解封小红书抖音账号"
```

**Target 格式**: `平台:UID:用户名:商品/卖家描述`

**安全说明**: 
- Phase 1 对话双方均为LLM模拟，不连接真实平台
- 安全护栏自动阻止付款/身份验证/加密渠道等风险行为
- Phase 2 (后续) 才会连接真实平台进行被动式情报收集

## 完整工作流

```bash
# 1. 采集
python main.py collect -p weibo -k "刷单,接码,跑分" --max-pages 5
python main.py collect -p zhihu -k "刷单,接码,跑分" --max-pages 5
python main.py collect -p xianyu -k "账号交易,涨粉" --max-pages 2

# 2. 清洗去重
python main.py clean -l 500

# 3. 分析（分类+实体+证据+风险）
python main.py analyze -l 200

# 4. 看 Dashboard
python main.py ui
```

> LLM 需要有效的 `.env` 中 `BGI_LLM_API_KEY`。无 Key 时自动降级到 L1+L2。

## 故障排查

| 症状 | 原因 | 解决 |
|------|------|------|
| 采集返回 0 条 | Cookie 过期 | `python login_edge.py <平台>` |
| 闲鱼 0 条/验证码 | 阿里反爬触发 | 等15分钟；限量20-30条/次；不要最小化浏览器 |
| 闲鱼登录失败 | 需手动扫码 | 首次启动保持浏览器可见，手动扫码登录 |
| 抖音 0 条 | 反爬/引擎变动 | 换关键词或等30分钟 |
| 贴吧 0 条 | 百度验证码 | 重新登录；百度反爬强结果少属正常 |
| QQ群无连接 | NapCatQQ未启动 | 启动NapCatQQ；确认 ws://localhost:3001 |
| GBK 乱码 | Windows 编码 | `PYTHONIOENCODING=utf-8` |
| LLM 401 | Key 无效 | 编辑 `.env` 填入真实 Key |
| Docker 连不上 | Docker 未启动 | 启动 Docker Desktop |
