## 快速开始

```bash
cd "E:\pythonProject\2605 灰黑产Agent比赛\BGI"

# 1. 确保 Docker 运行
docker ps  # 应有 bagi_mysql, bagi_neo4j, bagi_etcd, bagi_minio, bagi_milvus, bagi_attu

# 2. 登录渠道（会弹出 Edge 浏览器，手动扫码后按 Enter）
python login_edge.py zhihu weibo tieba xiaohongshu douyin

# 3. 采集数据
python main.py collect -p weibo -k "刷单,诈骗" --max-pages 2

# 4. 清洗
python main.py clean -l 500

# 5. 查看 UI
python main.py ui
```

## 各渠道采集命令

### 微博（最快，12.8条/秒）
```bash
python main.py collect -p weibo -k "关键词1,关键词2,..." --max-pages 3
```
- 纯 HTTP 请求，无需浏览器
- Cookie 过期后运行 `python login_edge.py weibo`

### 抖音
```bash
python main.py collect -p douyin -k "关键词1,关键词2" --max-pages 1
```
- 需要 Playwright + Edge 浏览器
- 反爬较强，单次搜索约 20 秒
- 如果连续限流，等 30 分钟后再试

### 知乎
```bash
python main.py collect -p zhihu -k "关键词1,关键词2" --max-pages 2
```

### 小红书
```bash
python main.py collect -p xiaohongshu -k "关键词1,关键词2" --max-pages 2
```

### 贴吧
```bash
python main.py collect -p tieba -k "关键词1,关键词2" --max-pages 2
```

## 故障排查

| 症状 | 原因 | 解决 |
|------|------|------|
| 采集返回 0 条 | Cookie 过期 | `python login_edge.py <平台>` |
| 抖音限流 | 请求太频繁 | 等 30 分钟 |
| Docker 连不上 | Docker Desktop 未启动 | 启动 Docker Desktop |
| GBK 编码错误 | Windows 默认编码 | `PYTHONIOENCODING=utf-8` |
| LLM 401 | API Key 无效 | 编辑 `.env` 填入真实 Key |
