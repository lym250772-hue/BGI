```bash

# 1. 启动 Docker

# 2. 安装依赖

python main.py init-db

# 5. 启动 Dashboard
python main.py ui
```

## 采集命令

### 单平台采集

```bash
# 微博（纯 HTTP，~8条/秒）★最快
python main.py collect -p weibo -k "刷单,接码,跑分" --max-pages 5

# 知乎（纯 HTTP API，含答案+评论）
python main.py collect -p zhihu -k "刷单,接码,跑分" --max-pages 5

# 小红书（Playwright API拦截+DOM兜底）
python main.py collect -p xiaohongshu -k "刷单,接码" --max-pages 3

# 抖音（Playwright 首页搜索框+正则提取）
python main.py collect -p douyin -k "刷单,接码" --max-pages 3

# 贴吧（Playwright DOM解析，百度反爬强，约0.03条/秒）
python main.py collect -p tieba -k "刷单" --max-pages 2
```

### 选项

| 选项 | 默认 | 说明 |
|------|:--:|------|
| `-p, --platform` | telegram | 目标平台 |
| `-k, --keywords` | — | 逗号分隔搜索关键词 |
| `--max-pages` | 10 | 每关键词最大翻页数 |
| `--fetch-replies` | True | 是否采集回复/评论 |

### 批量样本采集

```bash
# 一键多平台采集，输出到 examples/
python scripts/collect_examples.py --max-pages 5 -k "刷单,接码,跑分,账号出售"

# 指定平台
python scripts/collect_examples.py --platforms weibo,zhihu -k "刷单" --max-pages 3
```

## 完整工作流

```bash
# 1. 采集
python main.py collect -p weibo -k "刷单,接码,跑分" --max-pages 5
python main.py collect -p zhihu -k "刷单,接码,跑分" --max-pages 5

# 2. 清洗去重
python main.py clean -l 500

# 3. 分析（分类+实体+证据+风险）
python main.py analyze -l 200

# 4. 看 Dashboard
python main.py ui
```

> LLM 需要有效的 `.env` 中 `BGI_LLM_API_KEY`。无 Key 时自动降级到 L1+L2。

## 故障排查

| 症状 | 原因 | 解决 |
|------|------|------|
| 采集返回 0 条 | Cookie 过期 | `python login_edge.py <平台>` |
| 抖音 0 条 | 反爬/引擎变动 | 换关键词或等30分钟 |
| 贴吧 0 条 | 百度验证码 | 重新登录；百度反爬强结果少属正常 |
| GBK 乱码 | Windows 编码 | `PYTHONIOENCODING=utf-8` |
| LLM 401 | Key 无效 | 编辑 `.env` 填入真实 Key |
| Docker 连不上 | Docker 未启动 | 启动 Docker Desktop |
